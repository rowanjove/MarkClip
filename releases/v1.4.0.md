# 页摘 1.4.0 · 新界面、新图标与稳定性修复

MarkClip 的对外产品名更新为「页摘」。本版重做弹窗、网页浮窗和区域选择提示，默认采用米白与墨绿色界面，保留深色主题。新图标以页面轮廓和向右移出的金色摘录表达“摘下网页内容”。

## 下载与安装

- 下载下方附件 `markclip-1.4.0.zip`，解压后在 Chrome / Edge 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”。
- 已安装解压版：覆盖原目录文件后点击“重新加载”，再刷新网页。不要先卸载，以免丢失本地设置。
- `SHA256SUMS.txt` 提供安装包校验值。GitHub 自动生成的 Source code 是源码归档；普通使用者请选择上述安装包。
- 保留 `MarkClip*` 内部命名和 `page2md:*` 本地设置键。历史 v1.3.0 Release 不覆盖。

## 本次更新

- 重做弹窗、浮窗与选区提示；精简视觉装饰，整理主要操作和“更多操作”，补齐键盘焦点、Escape 与忙碌状态。
- 同步更新 16/48/128 图标、商店素材、README 截图、设计规范和验收记录。
- 修复 SPA 异步准备期间跳转导致来源与内容混用、设置或地址变化后复用旧预览的问题。
- 修复浮窗在小视口越界、隐藏后被延迟初始化重新创建，以及网页无法加载浮窗图标的问题。
- 加固大页面转换的取消与超时、图片内嵌的时间与体积限制、懒加载图片地址与 Markdown/YAML 输出处理。
- 网页可访问资源仅新增 `icons/icon48.png`；未增加永久网页访问权限。浮窗仍需用户主动开启并授权。
