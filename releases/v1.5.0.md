# 页摘 1.5.0 · 统一架构升级、多浏览器支持与资料包导出

页摘 v1.5.0 是一次统一架构升级：采用 WXT + TypeScript + ES Modules 现代工程体系，覆盖 Chrome、Edge、Firefox 与 Safari 转换路线，提供深度结构化提取、多端扩展界面和本地资料包归档能力。

## 下载与安装

- Chrome / Edge：下载下方附件 `markclip-1.5.0-chrome.zip`，解压后在浏览器扩展管理页开启“开发者模式”，选择“加载已解压的扩展程序”。
- Firefox：下载下方附件 `markclip-1.5.0-firefox.zip`，在 `about:debugging` 中临时加载或签名安装。
- 源码包：`markclip-1.5.0-source.zip`。
- `SHA256SUMS.txt` 提供各安装包的哈希校验值。
- 升级说明：解压覆盖原目录并重新加载扩展即可，不要先卸载，扩展会自动平滑迁移旧版设置与站点规则。

## 本次更新

1. **统一第二代架构**：
   - WXT + TypeScript + ES Modules，支持 Chrome MV3、Firefox MV3 及 Safari 转换路线。
2. **三级最小权限控制**：
   - 默认仅按需使用 `activeTab` 权限；页面浮窗采用站点级与全站级动态权限，关闭时注销动态脚本。
3. **Smart 提取链与声明式 Recipe 2.0**：
   - `Recipe -> Defuddle -> Readability -> Semantic` 降级提取；
   - 声明式 Site Recipe 支持 JSON/YAML 导入导出，严禁执行任意 JS；
   - 增强 Metadata Pipeline 解析 OpenGraph 与 JSON-LD。
4. **标准化清洗与渲染 Profile**：
   - 相对 URL 绝对化、懒加载图片恢复、GFM 表格、安全代码围栏、LaTeX/MathML 数学公式、Callout 与脚注；
   - 内置 CommonMark、GFM、Obsidian 预设，支持可自定义 Profile。
5. **离线资料包（Assets ZIP）**：
   - 支持 Remote、Remove、Embed 以及 Assets 模式；
   - Assets 模式将正文、本地图片、元数据及安全 Snapshot 打包为独立离线 ZIP。
6. **全套交互界面与任务队列**：
   - 新增 Chrome Side Panel / Firefox Sidebar、右键菜单、快捷键与 Options 页面；
   - 批量任务队列支持并发、暂停、恢复、取消和失败重试；支持批注高亮提取与 WebDAV/GitHub/Joplin 适配器。
7. **可选 AI 增强**：
   - 客户端直连兼容接口，默认关闭，异常自动安全回退原始内容。

- E2E 测试：Chromium MV3 Service Worker、浮窗拖动边界、Chrome CDP 真实渲染及 WXT Fixture 验证全部通过。
